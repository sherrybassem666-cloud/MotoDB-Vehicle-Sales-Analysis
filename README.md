# Vehicle Sales Data Analytics

## 📌 Project Overview

An end-to-end data analytics project focused on analyzing vehicle sales data
and extracting meaningful business insights from the dataset.

## 🛠️ Tools & Technologies

- SQL Server
- Python
- Pandas
- NumPy
- Power BI
- Excel

## 🔄 Project Workflow

Raw Data
↓
SQL Server
↓
Data Cleaning & Transformation
↓
Exploratory Data Analysis
↓
Power BI Dashboard
↓
Business Insights & Presentation

## 🧹 Data Cleaning

The data was cleaned and prepared for analysis by handling:
- Missing values
- Duplicate records
- Data types
- Outliers
- Inconsistent values

Additional analytical columns were created, including:
- Vehicle Age
- Odometer Group
- Condition Group
- Price Difference
- Price to MMR

## 📊 Power BI Dashboard

The dashboard provides insights into:

- Total Sales
- Vehicles Sold
- Average Selling Price
- Average Price to MMR
- Sales Trends
- Top Makes
- Body Types
- Condition
- Mileage
- Geographic Distribution

## 💡 Key Insights

• 558,799 vehicle sales analyzed
• $7.43B total sales value
• $13,302.85 average selling price
• 48.08% of vehicles sold above MMR
• 49.98% sold below MMR
• 97 unique makes and 974 models
• 16.74% of transactions were Ford vehicles
• Sedans represented 43.19% of total transactions
• Vehicle mileage showed a -0.652 correlation with selling price
• MMR showed a +0.982 correlation with selling price
